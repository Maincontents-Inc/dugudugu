# 두구두구 🥁

팀 순서를 **공정하게** 정하는 웹 미니게임 플랫폼입니다.
행사·캠프 현장에서 프로젝터에 띄워놓고 진행자가 클릭만 하면 됩니다.
발표 순서, 상품 추첨, 순위 정하기 — **용도를 고르면 화면 표현이 통째로 바뀝니다.**

- 빌드 도구 없는 정적 사이트 — GitHub Pages에 그대로 올라갑니다
- 파일을 내려받아 `index.html` 을 더블클릭해도 그대로 동작합니다 (인터넷 불필요)
- **PC·태블릿·폰 모두 대응** — 프로젝터에 띄워도, 폰으로 열어도 동작합니다
- 모든 게임이 **2~20팀** 지원
- 행사 제목·부제·글꼴을 넣으면 게임 화면과 결과, 저장 이미지에 함께 표시됩니다

## 게임

| 게임 | 설명 |
|---|---|
| 🪜 **사다리타기** | 팀마다 구슬이 사다리를 타고 내려가 순서를 정합니다. 한 팀씩 개별 진행 또는 전체 동시 진행. |
| 🎱 **마블 레이스** | 팀마다 구슬이 코스를 굴러 내려가고, 결승선을 통과한 순서가 그대로 결과가 됩니다. |

## 쓰는 법

1. **팀 이름**을 넣습니다. `여러 줄 붙여넣기` 로 엑셀·메모장에서 한 번에 넣을 수 있고, 팀 수는 자동으로 맞춰집니다.
2. **행사 정보**(선택)에 제목·부제를 넣으면 게임 화면 왼쪽 위와 결과 화면, 저장 이미지에 표시됩니다. 비워두면 아무것도 나오지 않습니다.
   같은 칸의 **용도**를 고르면 결과 화면·도착 칸·저장 이미지의 표현이 한꺼번에 바뀝니다.
3. **게임**을 고르고 `시작하기`.
4. 결과가 나오면 `결과 이미지 저장` 으로 PNG를 받아 공지에 쓸 수 있습니다.

설정은 브라우저에 자동 저장되어 다음에 열어도 그대로 유지됩니다.

### 용도 프리셋

| 용도 | 결과 화면 제목 | 각 자리 | 저장 파일명 |
|---|---|---|---|
| 순서 정하기 (기본) | 순서 | `1번` | `순서_20260918.png` |
| 발표 순서 | 발표 순서 | `1번째 발표` | `발표순서_…` |
| 순위 | 순위 | `1등` | `순위_…` |
| 추첨 당첨 | 당첨 순서 | `1번째` | `추첨결과_…` |

문구는 `assets/core.js` 의 `PURPOSES` 한 곳에만 있습니다. 용도를 추가하려면 거기에 한 줄 넣으면
모든 게임에 자동으로 적용됩니다. 게임 쪽은 `host.slot(j)` 만 부르면 되므로 게임이 늘어나도
문구를 게임마다 고칠 일이 없습니다.

### 화면 크기

| 환경 | 동작 |
|---|---|
| 프로젝터·노트북 | 전체화면(`F`)으로 띄워 진행 |
| 태블릿 | 그대로 동작 |
| 폰 (세로) | 설정은 한 열로, 마블은 코스 위 순위 아래로 쌓입니다. 사다리는 칸 폭을 지키고 좌우로 밀어 보며, 구슬이 움직이면 화면이 따라갑니다 |
| 폰 (가로) | 세로 공간을 아끼려 부제·안내문을 숨깁니다 |

### 단축키

| 키 | 동작 |
|---|---|
| `F` | 전체화면 (프로젝터용) |

## 공정성

**두 게임 모두 모든 순서가 정확히 같은 확률로 나옵니다.** 원리는 다르지만 뿌리는 같습니다 —
`crypto.getRandomValues` 기반 Fisher-Yates 셔플입니다.

### 사다리타기 — 결과를 먼저 뽑고 사다리를 역산

가로줄을 무작위로 뿌리기만 하는 일반적인 사다리는 균등하지 않습니다. 사다리는 한 번에 옆으로
한 칸씩만 움직이는데 연결선 개수가 유한하니, 끝 줄은 끝에 머무를 확률이 높습니다.
(5팀·14행 실측: 1번 줄 → 1번 도착 **27.0%** vs 5번 도착 **12.7%**)

그래서 순서를 뒤집었습니다.

1. 결과 순열 π 를 균등하게 **먼저** 뽑습니다
2. 위·아래에 자유 랜덤 블록 A, B 를 깝니다
3. 가운데 보정 블록 C 를 **odd-even transposition network** 로 만들어 `B∘C∘A = π` 가 되게 맞춥니다 (`C = B⁻¹∘π∘A⁻¹`)

같은 결과를 만드는 사다리 모양이 무수히 많아서 **사다리는 매번 새로 그려집니다.**
상단 팀 순서는 입력한 그대로 고정되고, 화면의 사다리를 실제로 타고 내려간 결과가 곧 최종 결과입니다.
보정이나 눈속임은 없습니다.

### 마블 레이스 — 출발 슬롯을 균등하게 섞기

물리 시뮬레이션은 출발 위치에 따라 유불리가 생깁니다. 그래서 **출발 슬롯에 팀을 배정할 때**
균등 셔플을 씁니다.

- 구슬은 색과 번호만 다를 뿐 크기·질량·마찰이 완전히 동일합니다
- "어느 슬롯이 몇 등으로 들어오는가"는 물리가 정하고, "그 슬롯에 어느 팀이 있는가"는 균등 난수가 정합니다
- 최종 순위 = (슬롯 도착 순서) ∘ (균등 셔플) → 모든 n! 순서가 같은 확률

코스가 아무리 편향돼 있어도 결과는 완전 균등합니다. 공은 진짜로 굴러갑니다.

### 직접 확인하기

브라우저에서 페이지를 열고 개발자도구 콘솔(F12)에 입력하면 직접 검증할 수 있습니다.

```js
__ladderAudit(5)        // 사다리 5팀 6만 회: 불일치 0, 출발×도착 분포
__ladderAudit(20, 5)    // 20팀
Core.auditShuffle(5)    // 셔플 균등성 (마블 공정성의 근거)
Core.auditShuffle(20)
```

`mismatch: 0` 은 "사다리를 실제로 타고 내려간 도착점"이 "뽑힌 결과"와 100% 일치한다는 뜻입니다.

## 사다리만 담은 단일 HTML

`사다리타기.html` — 사다리타기 하나만 들어 있는 **파일 한 개** 버전입니다.
`assets/` 없이 그것만 복사해 어디서든 더블클릭하면 실행됩니다. 메일로 보내거나
USB에 담아 현장 노트북에서 바로 쓸 때 편합니다. 기능·공정성은 동일합니다.

공용 파일(`assets/`)을 고친 뒤에는 아래 명령으로 다시 만들어야 반영됩니다.

```bash
node tools/build-single.mjs ladder "사다리타기" "사다리타기.html"
```

다른 게임도 같은 방식으로 뽑을 수 있습니다.

```bash
node tools/build-single.mjs marble "마블 레이스" "마블레이스.html"
```

게임이 하나만 등록된 빌드에서는 '게임 선택' 영역이 자동으로 숨겨집니다.

### 게임 추가하는 법

`assets/game-<이름>.js` 를 만들고 `index.html` 에 `<script>` 한 줄을 추가하면 끝입니다.

```js
Core.registerGame({
  id:'wheel', icon:'🎡', name:'룰렛', desc:'설명',
  optionsHtml(){ return '...'; },          // (선택) 설정 화면에 표시할 옵션 HTML
  bindOptions(root, o, save){ ... },       // (선택) 옵션 이벤트 연결
  start(h){ /* h.stage 에 그리고 h.finish(results) 로 끝낸다 */ },
  onResize(){}, onShow(){}, onKey(e){}, stop(){}
});
```

`h.finish(results)` 의 `results[j]` 는 **j+1번째 자리를 맡을 팀의 인덱스**입니다.
자리 이름은 `h.slot(j)` 로 가져오세요 (용도 프리셋이 반영된 문구가 나옵니다).
호스트가 제공하는 것: `h.teams`, `h.n`, `h.stage`, `h.settings`, `h.opts()`,
`h.tool(html)`(상단 버튼 추가), `h.slot(j)`·`h.purpose`(용도 프리셋 문구),
`h.setTip()`, `h.setCounter()`, `h.countdown()`,
`h.rnd/rndInt/shuffle`(암호학적 난수), `h.esc`, `h.lighten`, `h.toast`.

## 알려진 제약

- 새로고침하면 추첨 결과는 초기화됩니다(설정은 유지). 결과는 PNG로 저장해 두세요.
- 팀 수 상한은 20팀입니다. 그 이상은 화면에서 읽기 어렵습니다.
- 크롬 기준으로 테스트했습니다.
